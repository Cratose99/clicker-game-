# Clicker Game

A memory clicker: click every relic once. The board shuffles after each click. Click the same relic twice and the run is over.

## How to play

1. Click a card you have not clicked yet this run.
2. Your score goes up by one and the cards shuffle.
3. Click all 12 unique relics to win.
4. Click a repeat and the score resets. Your top score is kept in this browser.

## Scripts

```bash
npm install
npm run dev
npm test
npm run build
```

Open the local URL printed by `npm run dev` (usually http://localhost:5173).
